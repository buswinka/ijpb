ImageJ Pipeline Builder has moved

IJPB is now Nissl

Nissl does everything ImageJ Pipeline Builder did, and goes further: better automations, figure making, interactive analysis, and more.

Get Nissl at chromatype.bio →

What this means for IJPB users

  • The IJPB plugin is no longer maintained and won't receive further updates.
  • The IJPB cloud service has shut down.
  • Saved IJPB pipelines don't carry over to Nissl.
  • To remove the plugin, open Fiji and run Plugins › Utilities › Pipelines › Uninstall.
